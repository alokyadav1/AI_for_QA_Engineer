## SMART Framework

```
Task:
Generate test cases using SMART framework.

Specific: Focus on one functionality only.
Measurable: Output must be testable.
Achievable: Avoid assumptions.
Relevant: Think from QA perspective.
Time/Format Bound: Follow requested format strictly.

Now generate test cases for the given feature.

```

## CRISP Framework

```
Act as a Senior QA Engineer.

Follow these rules strictly:
- Adhere to requirements
- Stay within defined scope
- Do not assume missing data
- Output in requested format only

```

## Prompt Generator

```
Act as a QA Prompt Generator.

Ask me structured questions to gather:
- Application context
- Feature scope
- User type
- Testing type
- Output format

After collecting answers, generate an optimized QA prompt.

```

## Test Case Generator

```
Act as a Senior QA Engineer.

Analyze the given functionality carefully.
Think step by step.

Generate:
- Positive test cases
- Negative test cases
- Boundary test cases
- Edge cases

Output in Gherkin format.
Do not assume missing requirements.

```

## Bug Analysis

```
Act as a Senior QA Engineer.

Analyze the reported bug step by step.
Identify:
- Possible root causes
- Missing test scenarios
- Risk areas

Provide analysis before conclusions.
```

## Test Coverage Review

```
Act as a QA Lead.

Review the given test scenarios.
Identify:
- Gaps in coverage
- Redundant cases
- High-risk missing areas

Suggest improvements clearly.
```

## Automation Ready Gherkin

```
Act as an Automation QA Engineer.

Generate Gherkin scenarios:
- Using reusable steps
- Avoiding hard-coded data
- Following Given-When-Then strictly
```
