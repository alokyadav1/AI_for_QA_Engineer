```markdown
Act as a Senior QA Lead.

- Testing objectives
- Test types
- Automation approach

- Environments
- Entry and exit criteria
- Defect management approach

```
## Web Application Test Strategy

```
1. Objective
Ensure functional correctness, stability, and usability of the web application.

2. Scope
Includes UI, API, integration, and regression testing.

3. Test Types
- Functional Testing
- Integration Testing
- Regression Testing
- Smoke & Sanity
- Security (basic)
- Performance (basic)

4. Automation Strategy
- Critical user flows automated
- Regression automation using Cypress
- API automation for core services

5. Risk Areas
- Authentication & authorization
- Payment & checkout
- Data consistency

6. Environments
- QA
- Staging
- Production (sanity only)

7. Entry & Exit Criteria
Defined based on test coverage and defect severity.

```
